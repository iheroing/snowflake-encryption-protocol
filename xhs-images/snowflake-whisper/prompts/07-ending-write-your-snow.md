# 07｜写下你的第一封雪信

Use case: ads-marketing
Asset type: 小红书 3:4 结尾体验卡片
Primary request: 制作克制、留白充分的体验邀请页。
Scene/backdrop: 近黑蓝背景，中央是一枚很小的发光雪花，周围像呼吸一样留白。
Composition/framing: 上方为问题；中间雪花；下方真实可扫描二维码、网址与 CTA。
Text (verbatim):
- 「你有一句，只想认真说一次的话吗？」
- 「轻触封印，让它凝成一片独一无二的雪」
- 「www.liyi.online/snowflake」
- 「收藏这篇，等那个时刻到来」
Constraints: 二维码由本地程序生成并后期加入；背景图不绘制二维码和文字；无水印。
Avoid: 点赞三连、巨大箭头、促销按钮、节庆装饰。
